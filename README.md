# Mote

轻量**通用 agent**：本地小模型做前置路由，云端大模型负责回答，省下大部分 token。
零第三方依赖、纯 Python 标准库、单页内联网页，跑在自己的机器上。

```
你发一个问题
  └→ 本地 qwen 一次调用：路由 / 压缩上下文 / 预选工具
       ├─ 简单问题 → 本地直接回答，云端 0 token
       └─ 复杂问题 → 只把压缩后的上下文交给云端
```

## 它做到了什么

| | |
|---|---|
| **省 token** | 一条混合链路只发 700 字上下文，而不是整段历史；每条回答都标注实际模型和省下的字数，可核对 |
| **不留退化** | 云端不可用、key 缺失、路由器解析失败，都会自动回退，不会把请求丢给错误的一方 |
| **分支对话** | 同一问题可以有多条回答并存，`1/N` 切换；编辑后另开分支，原分支完整保留 |
| **分支树可视化** | 1080 个问题的会话画成约 4200×6900px 的 SVG，渲染约 0.1 秒，点圆点即跳转 |
| **可中断** | 生成中随时停止，已生成内容保留；一个字都没有时整轮撤回，不留空问答 |
| **离线可用** | 页面无 CDN、无第三方脚本；全部 120 个测试不联网、不调模型 |
| **零安装负担** | 不用 `pip install`，Python 3.9+ 直接跑 |

## 30 秒跑起来

```bash
git clone https://github.com/Unlimitedlearning/Mote.git
cd Mote
python -m mote serve          # 自动打开 http://127.0.0.1:9000/
```

第一次打开会自动弹出设置面板：填接口地址、模型名和 API Key，点「测试连接」确认即可，
不用改文件、不用重启。默认配好 DeepSeek 与本地 Ollama，也可以用环境变量：

```bash
export DEEPSEEK_API_KEY=sk-xxx
```

命令行同样能用：

```bash
python -m mote ask "有个 offer 但想读研，怎么判断选哪个"
python -m mote chat                      # 终端对话
python -m mote --no-hybrid ask "在吗"    # 关闭本地前置，直连云端
python -m mote --local ask "在吗"        # 只用本地端点，不发任何云端请求
```

## 界面

左栏会话列表（搜索、分组、重命名、导出、备份），右栏聊天区（Markdown 渲染、代码复制、
流式输出、思考过程折叠）。顶栏三个按钮：**查找**、**分支树**、**设置**；
`Ctrl+F` 只在本对话里查：回车定位，`↑`/`↓` 逐处看。
设置里可切**白天 / 黑夜**配色，即时生效、只记在本机浏览器。

每条问题下方有 `1/2` 分支序号与 `···` 菜单（删除、编辑重问、设为主分支、导出）；
每条回答下方有模型标签、重新生成、以及中断后的「已停止生成」标记。
配置、接口、记忆机制等实现细节都放在 [`docs/`](#文档) 里。

## 工具与镜头

工具是插件：`@tool(name, description, schema)` 注册，`agent.tools` 是白名单，
传给云端的 schema 按白名单与路由器预选结果过滤。核心不认识具体业务。

| 工具 | 作用 |
|---|---|
| `now` | 当前日期、时间、星期；涉及"现在/今天"必须调用 |
| `use_lens` | 可选插件：按需加载一个思维镜头的提问清单 |

镜头只保留手写的 **46 个**（`mote/services/lenses.py`，七大类别），存的是「问什么」而不是第三方文案，
所以仓库轻量、无版权负担、不依赖外部站点。

```bash
python -m mote lenses --id inversion   # 某个镜头的提问清单
```

## 从 DeepSeek 迁移对话

把 DeepSeek 导出的 zip 拖进 `deepseek对话迁移/`，双击 `运行.bat` 即可：
自动解压、找到 `chat_sessions`、转成 Mote 会话，重复会话默认跳过。
支持完整消息树，含真实分支的会话导入后可直接用分支树查看。
详见 [`deepseek对话迁移/README.md`](deepseek对话迁移/README.md)。

## 代码结构

```
mote/
  core/        纯逻辑：配置模型、上下文、事件树、导出、路由规则
  infra/       IO：配置文件、事件日志、模型客户端
  services/    用例：会话、检索、设置、问答编排、工具与镜头
  interfaces/  接入：HTTP、网页、终端
  __main__.py  参数解析与派发
```

依赖只能从上往下：接入层可以调服务层，服务层可以调基础设施与纯逻辑，
反过来不允许。`tests/test_layers.py` 用 AST 解析每个模块的相对导入，
任何向上的依赖都会让测试失败。纯逻辑层不碰磁盘，所以分支树、导出、路由解析
都能用构造好的数据直接测试。
