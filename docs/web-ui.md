# 网页界面

单文件实现（`mote/web.py` 里就是 HTML/CSS/JS 原文），**无 CDN、无第三方脚本、离线可用**。
不用构建工具，改完刷新即可。

## 布局

左栏会话列表，右栏可滚动聊天区。左栏顶部是搜索框，底部是「备份」；
会话项右侧 `···` 可以重命名、删除、导出、设为主分支。

右侧历史很长的会话默认只渲染最近 40 条，顶部「加载更早的 N 条」每次多渲染 150 条，
所以 1000 轮以上的导入会话也能立刻打开；从搜索或分支树跳到更早的消息时窗口自动扩到那一条。

## 发送与生成

发送后立刻出现带计时的"思考中"；正文按字流式出现（SSE + chunked），
推理原文同步写进可展开的「思考过程」面板（生成中默认展开，完成后折叠）。
思考原文也按 Markdown 渲染：小标题、列表、引用、行内代码、代码块都保留结构，
长推理在 320px 内滚动，不挤占正文高度。

每条回答下方显示**模型标签**（`本地 · qwen3.5:4b` / `云端 · deepseek-chat`）和这一轮省下的字数。

生成中发送按钮变成 `■`，点击立即中断：

- 已流出的正文会保存，回答下方标「已停止生成」；
- 一个字都没生成时，本轮整体撤回，历史里不留空问答；
- 前端用 `AbortController` 断开连接，随后以服务端 `/messages` 为准做一次校准。

每条回答下方有「重新生成」：在同一问题处另开一个同级分支，旧回答留在 `1/N` 序号里可切回；
请求失败时显示原因并给「重试」，不用重新输入问题。

## 分支

- 问题下方显示 `1/2` 和左右箭头，点击切换兄弟分支；切换后展示该分支自己的完整后续，
  而不是停在分叉那一轮。
- 问题下方 `···` 菜单：删除该问答及后续（只影响当前分支，兄弟保留），
  或编辑后从该处另开分支。
- 「设为主分支」把当前链路钉成默认入口：重新打开对话就落在这条链上；
  已在该链上时菜单变成「取消主分支」。

**主分支只是标记，不限制跳转**：点分支树、`1/N`、提问、删除都以"当前视图的链路末端"为准，
前端统一从消息流里取最后一个 user 节点的 `node` 作为 `parent` / `?node=` / `?tip=`。

## 分支树

顶栏「⑂ 分支树」把整段对话画成一棵自上而下的树。要点：

- **坐标在 JS 里算好，画成一张 SVG**，不用 CSS 伪元素拼连线——后者会出现横线横穿子树、
  竖线断头、悬空线段。
- 后序布局：叶子按顺序占位，父节点落在首末子节点的中点，所以单链是一条竖线，
  只有出现兄弟分支时才横向展开。
- 连线是直角加 7px 圆角肘弯（`M` / `L` / `Q`），不会穿过节点。
- 层距与列距按规模自适应：`LV = min(34, max(13, 5200/depth))`、
  `GAP = min(26, max(11, 4000/leaves))`。
- 节点只画圆点，不显示正文（问题摘要放在 `<title>` 里，悬停可见）；
  点击圆点即切到那条分支，走 `[data-node]` + `closest`，对 SVG 元素同样有效。

1080 个问题的大会话压到约 4200×6900px（而不是两万多像素高），整个图渲染约 0.1 秒。
打开时自动把当前位置滚到视野中间，分支多时弹窗可横向滚动。

### 配色

| 元素 | 颜色 |
|---|---|
| 当前所在链路 | 蓝 `#5b8bf0` |
| 主分支链路 | 绿 `#2fa36b` |
| 两者重合 | 蓝底 + 绿描边 |
| 其它分支 | 灰 |

图例四项与之一一对应。`main_path` 由服务端回溯给出，前端不自己算。

## 搜索

左侧搜索框同时做两件事：按标题过滤会话，并对全部会话的**问题与回答正文**做全文检索。

- 空格分隔的多个词需要同时命中；结果按命中次数排序；
- 片段里的关键词高亮，点一条结果即打开对应会话、切到该分支，并把那条消息滚到视野内闪烁一下；
- 输入 260ms 防抖，检索在后端逐会话扫事件、跳过已删除节点。

## 设置面板

顶栏「⚙ 设置」与「⑂ 分支树」同款按钮。面板分三组：**问答方式**（本地处理 → API / 直接云端）、
**云端模型**、**本地模型**。云端组可改接口地址、模型名、API Key、思考模式开关；
本地组可改端点、模型名、是否启用本地前置。「测试连接」会真的发一次请求。

没有配本地 profile 时「本地处理 → API」被禁用并提示只能用「直接云端」，
不会让人选到跑不通的路径。新用户首次打开（`needs_setup`）会自动弹出面板。

## 导出

会话 `···` 菜单可把当前分支导出为 Markdown（问题用引用块，回答保留原始 Markdown，
思考折叠在 `<details>` 里，末尾标注本地/云端与模型名）或导出带全部分支的 JSON；
侧栏底部「备份」把全部会话一次导出成单个 JSON。
