# 网页界面

页面仍以单响应返回（`mote/interfaces/web/page.py` 把模板与 `assets/` 里的 CSS/JS 拼成一页），
**无 CDN、无第三方脚本、离线可用**。
不用构建工具，改完刷新即可。

## 布局

左栏会话列表，右栏可滚动聊天区。左栏顶部是搜索框，底部是「备份」；
会话项右侧 `···` 可以重命名、删除、导出、设为主分支。

右侧历史很长的会话默认只渲染最近 40 条，顶部「加载更早的 N 条」每次多渲染 150 条，
所以 1000 轮以上的导入会话也能立刻打开；从搜索或分支树跳到更早的消息时窗口自动扩到那一条。
对话内查找跳到很旧的命中时只把窗口挪到那一条附近（前后各几十条），末尾补「加载更新的 N 条」，
两侧都能翻，不会因为定位一句话重绘整段历史。

## 发送与生成

发送后立刻出现带计时的"思考中"；正文按字流式出现（SSE + chunked），
推理原文同步写进可展开的「思考过程」面板（生成中默认展开，完成后折叠）。
思考原文也按 Markdown 渲染：小标题、列表、引用、行内代码、代码块都保留结构，
长推理在 320px 内滚动，不挤占正文高度。

每条回答下方显示**模型标签**（`本地 · qwen3.5:4b` / `云端 · deepseek-chat`）和这一轮省下的字数。

生成中发送按钮变成 `■`，点击立即中断：

- 已流出的正文会保存，回答下方标「已停止生成」；
- 一个字都没生成时，本轮整体撤回，历史里不留空问答；
- 连接中途断掉（不是用户点的）按同样的规则保留正文，提示改为「连接中断，已保留上面生成的内容」；
- 前端用 `AbortController` 断开连接，随后以服务端 `/messages` 为准做一次校准。

每条回答下方有「重新生成」：在同一问题处另开一个同级分支，旧回答留在 `1/N` 序号里可切回；
请求失败时显示原因并给「重试」，不用重新输入问题。

## 分支

- 问题下方显示 `1/2` 和左右箭头，点击切换兄弟分支；切换后展示该分支自己的完整后续，
  而不是停在分叉那一轮。
- 问题下方 `···` 菜单：删除该问答及后续（只影响当前分支，兄弟保留），
  或编辑后从该处另开分支。
- 「设为主分支」把当前链路钉成默认入口：重新打开对话就落在这条链上；
  已在该链上时菜单变成「取消主分支」。

**主分支只是标记，不限制跳转**：点分支树、`1/N`、提问、删除都以"当前视图的链路末端"为准，
前端统一从消息流里取最后一个 user 节点的 `node` 作为 `parent` / `?node=` / `?tip=`。

## 分支树

顶栏「⑂ 分支树」把整段对话画成一棵自上而下的树。要点：

- **坐标在 JS 里算好，画成一张 SVG**，不用 CSS 伪元素拼连线——后者会出现横线横穿子树、
  竖线断头、悬空线段。
- 后序布局：叶子按顺序占位，父节点落在首末子节点的中点，所以单链是一条竖线，
  只有出现兄弟分支时才横向展开。
- 连线是直角加 7px 圆角肘弯（`M` / `L` / `Q`），不会穿过节点。
- 层距与列距按规模自适应：`LV = min(34, max(13, 5200/depth))`、
  `GAP = min(26, max(11, 4000/leaves))`。
- 节点只画圆点，不显示正文（问题摘要放在 `<title>` 里，悬停可见）；
  点击圆点即切到那条分支，走 `[data-node]` + `closest`，对 SVG 元素同样有效。

1080 个问题的大会话压到约 4200×6900px（而不是两万多像素高），整个图渲染约 0.1 秒。
打开时自动把当前位置滚到视野中间，分支多时弹窗可横向滚动。

**缩放与平移**：页脚有 `−` / 比例 / `+` / 「适应宽度」，`Ctrl+滚轮` 以指针位置为锚点缩放，
点比例数字回到 100%；空白处按住拖动可以平移（位移超过 4px 才算拖动，松手时吞掉那一次 click，
不会误触跳转）。

- 实现用 CSS `zoom` 落在 `.tree-map` 上，滚动条长度与点击坐标都由浏览器一起缩放，
  不必重算坐标重画 SVG，缩小时也不模糊；
- 宽树首次打开会自动「适应宽度」（1080 节点约 25%），窄树保持 100%；
  手动调过缩放后就不再自动适应，改用按钮或 `Ctrl+滚轮`。

## 搜索

左侧搜索框同时做两件事：按标题过滤会话，并对全部会话的**问题与回答正文**做全文检索。

- 空格分隔的多个词需要同时命中；结果按命中次数排序；
- 片段里的关键词高亮，点一条结果即打开对应会话、切到该分支，并把那条消息滚到视野内闪烁一下；
- 输入 260ms 防抖，检索在后端逐会话扫事件、跳过已删除节点。

### 对话内查找

顶栏「⌕ 查找」或 `Ctrl+F` 打开一条查找栏，作用域是**当前打开的这个对话、当前这条分支**，
不跨会话。计数显示 `第几处/共几处`，没有命中时输入框变红。

打字阶段只记下输入、不查也不跳；按 `Enter` 才按当前输入定位到离视野最近的一处。
定位之后 `Enter`/`↓` 下一处，`Shift+Enter`/`↑` 上一处，`Esc` 关闭。

- 只匹配问题与回答正文（不含思考过程），按字面比较、忽略大小写，不做分词；
- 命中按数据算，DOM 只标当前窗口内的行：命中落在窗口外时，窗口挪到该条前后各几十条，
  下方补一个「加载更新的 N 条」，不会为了看一眼把上千轮历史整段重绘；
- 目标已在窗口内时翻命中只挪当前高亮与视野，不重铺标黄；1080 轮 / 2.1 万处命中的极端会话里，
  回车定位约 30ms，翻一处约 20–25ms。

## 设置面板

顶栏「⚙ 设置」与「⑂ 分支树」同款按钮。面板分四组：**外观**（白天 / 黑夜）、
**问答方式**（本地处理 → API / 直接云端 / 仅本地）、**云端模型**、**本地模型**。
云端组可改接口地址、模型名、API Key、思考模式开关；
本地组可改端点、模型名、是否启用本地前置。「测试连接」会真的发一次请求。

三种方式的区别：**本地处理 → API** 让本地模型先判断难易、压缩上下文，简单问题不调云端；
**直接云端** 每条都直连 worker，最快但每次联网；**仅本地** 只用本机端点回答，
一个字节都不发出去，也不需要云端 key。

没有配 local profile 时「本地处理 → API」与「仅本地」都会被禁用，并提示只能用「直接云端」，
不会让人选到跑不通的路径。新用户首次打开（`needs_setup`）会自动弹出面板；
选了「仅本地」之后即使没有云端 key 也不会再弹。

### 外观

白天 / 黑夜两张卡片，**点选即时生效**，不需要按「保存」，也不写进 `config.json`：
主题暂存在浏览器 `localStorage`（键 `mote-theme`），只影响当前这台机器上的这个浏览器。

- 首次打开没有记录时跟随系统 `prefers-color-scheme`，所以深色系统进来就是深色，不会先闪一下白屏
  （`<head>` 里有一小段脚本在绘制前把 `data-theme` 打在 `<html>` 上）；
- 配色用一套语义变量（`--panel` / `--muted-strong` / `--accent-line` / `--tree-dot` 等）挂在 `:root` 上，
  黑夜只覆盖 `html[data-theme="dark"]` 里的变量值，组件规则不用写两遍；
- 同时设了 `color-scheme`，滚动条、输入框光标、复选框这些原生控件也会跟着变深；
- 分支树的颜色全部来自 CSS 变量，切主题时 SVG 不需要重画。

代码块在两种主题下都保持深色底（`#1f2430`），黑夜下靠一圈极淡描边与正文区分。

## 导出

会话 `···` 菜单可把当前分支导出为 Markdown（问题用引用块，回答保留原始 Markdown，
思考折叠在 `<details>` 里，末尾标注本地/云端与模型名）或导出带全部分支的 JSON；
侧栏底部「备份」把全部会话一次导出成单个 JSON。
